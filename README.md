# Customer Data Cleaner

## Overview
A Python project that checks customer records for missing emails and duplicate IDs.

## Features
- Detects duplicate customer IDs.
- Identifies missing email addresses.
- Separates valid and invalid customer records.
- Saves results into separate CSV files.
- Displays record counts.

## Technologies
- Python
- CSV module
- Jupyter Notebook

## Output Files
- `valid_customers.csv`
- `invalid_customers.csv`

## How to Run
1. Open `customer_data_cleaner.ipynb` in VS Code.
2. Run the notebook cells in order.
3. Check the generated CSV files.
